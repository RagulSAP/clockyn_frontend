CLOCKYN TUTORIAL VIDEO LIST
===========================
29 videos (28 topics + 1 final walkthrough) for people who have never used Clockyn. Not one video per FAQ: each video answers the one question
a new Admin or Employee asks at that moment. Make them with the skill "clockyn-screen-video" (SKILL.md in this folder).

HOW TO USE THIS FILE (for Copilot)
- The user picks videos by ID (for example "make V07"). Make ONE video per request, never all at once.
- Use the TITLE as config.json "question" (it is also the Video Hub name). Use SLUG as config.json "slug".
- The FLOW lines are a storyboard, not final wording. BEFORE writing narration, read the real screens
  (src/features/<feature>/screens, e2e/specs) and use the exact labels and testIDs that exist. If the real
  app differs from the FLOW, follow the real app and tell the user.
- Video LENGTH has NO limit. The "~25 to 60 s" estimates in this list are only a starting guess. The goal is that the end user can do the task after watching, so cover everything they need (all required fields and
  steps, the important optional parts, the result they should see, and the usual next action). If that needs 90 s or 3 minutes, make it that long. Never cut content to save time.
- Before recording, write down what a first-time user must know for this question and check every item is in the video.
- One main question and one clear outcome per video. Split into several videos only along natural tasks, and only when each part still fully answers its own question.
- NO step numbers in the video: never say "Step one / Step two", never write them in captions, keep the top-right label empty.
- SIGN-IN IS BY E-MAIL. Employees (and managers) sign in with their e-mail address. In every video: e-mail is REQUIRED, phone number is OPTIONAL, say "sign in with the email address", and record with `mock.setState({ userAuth: 'email' })`. Always run `npm run e2e:build` first so the video shows the current form (an old build still shows a red star on Phone Number).
- COMPANY NAME IS "AuroCloud" in EVERY video (past and future). Record with the environment variable VIDEO_ORG_NAME=AuroCloud (the mock server reads it
  in e2e/mock-server/fixtures.js; without it the screens show "Acme Traders"). In V01 type "AuroCloud" as the company name. After rendering,
  look at the stills for any leftover "Acme Traders" / "Sunrise Traders".
- ROLE = the role to log in as in the recording (loginAs): admin | manager | staff | fieldStaff.
- CAN RECORD: yes = plain app screens; partly = something in the flow cannot be shown in the web build
  (camera, GPS, payment gateway, push notification, OS permission pop-ups): show everything up to that point, narrate
  the rest, and say what is missing in the hand-over; no = needs a real phone, skip until the user asks.
- STATUS: DONE (file exists), REQUESTED (user already asked Copilot for it), TODO.
- Videos are for the Video Hub (web console > Video Hub > Upload video, MP4 up to 500 MB, name up to 150 chars).
