# Fixes applied: v1 defects fixed in Clockyn

This is the record of v1 behaviour that was **fixed on purpose** (as opposed to kept: see `docs/DEFERRED_DECISIONS.md`). It covers the 15 "rebuild traps" and the defect lists of the v1 build notes, the policy-level fixes of `docs/FIX_POLICY.md` section B, the per-area fixes that the engineers logged in `docs/changes/*.md`, and the gaps the QA audits found and fixed (`docs/qa/*.md`).

Conventions:

- **v1 reference** is "notes trap n" (the numbered table in the v1 build notes), "notes section n" of those notes, or the v1 spec page and section (`spec <page> §n`; §4 flows, §7 rules, §13 defects and fix list, §14 acceptance). Specs live in the v1 specification set (`../project_complete_context/pages/`, relative to the Clockyn folder, outside this repo).
- **Where** paths are relative to the repository root; **Pinned by** paths are relative to `src/` and name the test file (and, when useful, the test title).
- Status words: **Fixed** (v1 behaviour replaced), **Fixed in part** (the remainder is a decision, id given), **Kept** (listed because the trap asked for a decision; behaviour deliberately unchanged).
- This file is a curated index. The exhaustive per-screen lists are the "Fixes applied" sections of each change log.
