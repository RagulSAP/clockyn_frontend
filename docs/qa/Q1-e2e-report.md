## Observations / open items needing a decision (no change made)

1. **Plan-block copy for an expired paid plan** (Chat "Feature Unavailable"): `planBlockMessage` returns "Your free trial has ended. Please subscribe to the Core Plan..." for any expired/none plan, also for an expired paid plan. Spec copy (FIX_POLICY C) - product decision whether expired paid plans should read "plan has expired".
2. **Chat lists answer HTTP 500 `"403: ..."` when the plan is blocked** and the shell polls them on every page (documented backend quirk; the specs allow-list it). Backend should answer 403.
3. **Roster role chips** count by role regardless of the active flag, so "Inactive" overlaps "Staff"/"Manager" and "All Staff" lists inactive people while the dashboard "Total Staff" counts active only (rows != figure for the Total bucket). Spec behaviour, but potentially confusing.
4. **Punch edit allows out < in** (treated as next day by the server) - by design (overnight shifts); no warning is shown.
5. **Branch delete after full reassignment** falls back to a plain confirm dialog on failure; the server detail is only in a toast (the dialog's `error` state is not rendered).
6. **Switch component (shared UI)** in dark mode: the knob is dark on the primary track (ON) and dark-on-dark when OFF (low contrast). Left as is (shared component, design decision).
7. **Escape does not close sheets/dialogs unless focus is inside them** (react-native-web Modal behaviour); specs use the "Close dialog" button. Minor keyboard a11y gap.
8. Phone tab strip of the staff detail ("Overview / Calendar / Day-Wise / Location / Advance") scrolls horizontally with a hard clip ("Loca") and no affordance.
9. Pre-existing/foreign errors seen at the end of the run, not caused by Q1: `npx tsc --noEmit` reports `src/lib/platform/maps/ClockynMap.web.tsx(109,96)` (edited by another lead at 19:55) and `npm run e2e:typecheck` reports `e2e/specs/q3-11-visual.spec.ts(70,73)`.
